Home server● Ongoing

HomeLab

An always-on server on a spare laptop, built to learn the infrastructure side. Proxmox VE runs two virtual machines and three containers: Pi-hole for DNS, Caddy as a reverse proxy, Vaultwarden, Portainer, Uptime Kuma, and an Odoo 18 server on PostgreSQL with separate dev and production-style databases. Remote access goes through Tailscale, so no ports are open on the router. I use it to test Odoo automations with n8n. Next up: backups and a real restore test.
